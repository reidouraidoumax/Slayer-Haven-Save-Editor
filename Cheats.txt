#
# Action types and their keys (Offset/Length/Value/Count/Stride/Step accept hex
# like 0x1234 or plain decimal; Step may be negative):
#   Fill      Offset, Length, Value   - writes Value's low byte, Length times
#   Write8    Offset, Value           - writes one byte
#   Write16   Offset, Value           - writes a little-endian 16-bit value
#   Write32   Offset, Value           - writes a little-endian 32-bit value
#   Sequence  Offset, Count, Stride, Width, Value, Step
#             writes Count values of Width bits (8/16/32), starting at Value and
#             incrementing by Step each write; addresses step by Stride bytes.
#             This is the equivalent of a Save Wizard Type 4 (repeater) code.
