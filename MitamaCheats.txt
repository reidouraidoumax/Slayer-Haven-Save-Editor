# Toukiden 2 - Mitama cheats
#
# Same Cheats.txt grammar (see Cheats.txt for the full field reference).
# Table base 0x51A6D, stride 0x31 (49 bytes) per mitama, ids 0-199 (the 200
# official mitamas). Record layout:
#   0x00-0x23   9 x float32   skill proficiency (slots 0-8)
#   0x24-0x2C   9 x byte      skill level/stars (slots 0-8)
#   0x2D        byte          status (0x00 undiscovered, 0x0B unlocked)
#   0x2E-0x30   3 x byte      equipped boost 1-3 -> slot index (0-8), 0xFF none
#
# The "own all" cheats include an explicit Write8 forcing Admiral Perry
# (id 0xC7/199) after the repeater - confirmed by testing that the status
# repeater alone silently drops the very last entry in its range.
#
# Confirmed by testing: proficiency alone does not instantly max a skill -
# the in-game recalculation only grants one star per trigger and resets
# proficiency to 0 regardless of how much was stored.
